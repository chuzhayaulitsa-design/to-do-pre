# Сервис To-do

Проектная работа спринта «Продолжение JavaScript» — одностраничное приложение списка дел.

Пользователь может просматривать, добавлять, удалять, копировать и редактировать задачи. Все данные сохраняются в локальное хранилище (localStorage), поэтому изменения не теряются при перезагрузке страницы.

## Функциональность

- отображение текущих задач при загрузке страницы;
- добавление новой задачи через форму;
- удаление задачи;
- копирование задачи;
- редактирование текста задачи;
- сохранение списка задач в localStorage при каждом изменении.
